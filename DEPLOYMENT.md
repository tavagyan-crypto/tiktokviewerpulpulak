# 🚀 Deploy Your TikTok Viewer Online

Your TikTok Trending Viewer is now set up for automatic deployment!

## 📋 Deployment Options

### Option 1: Vercel (RECOMMENDED) ⭐

Vercel offers the best performance and easiest setup.

**Quick Deploy:**
1. Go to https://vercel.com/new
2. Select "GitHub" and authorize
3. Choose `tiktokviewerpulpulak` repository
4. Click "Deploy"
5. Your app goes live in ~2 minutes!

**Your Live URL:**
```
https://tiktokviewerpulpulak.vercel.app/
```

**Add Custom Domain:**
- Project Settings → Domains
- Add your custom domain
- Update DNS settings

---

### Option 2: GitHub Pages (FREE)

Automatic deployment from GitHub.

**Enable:**
1. Go to: https://github.com/tavagyan-crypto/tiktokviewerpulpulak/settings/pages
2. Under "Source", select "GitHub Actions"
3. Save changes
4. First deployment runs automatically

**Your Live URL:**
```
https://tavagyan-crypto.github.io/tiktokviewerpulpulak/
```

---

### Option 3: Netlify (FREE)

Easy drag-and-drop or Git-connected deployment.

**Connect GitHub:**
1. Go to https://app.netlify.com
2. Click "New site from Git"
3. Select GitHub and choose repository
4. Click "Deploy"

**Your Live URL:**
```
https://tiktokviewerpulpulak.netlify.app/
```

## 📝 Environment Variables

If adding real TikTok API later:

**Vercel:**
1. Project Settings → Environment Variables
2. Add `VITE_API_KEY=your_key`
3. Redeploy

**Netlify:**
1. Site Settings → Build & Deploy → Environment
2. Add variable
3. Redeploy
